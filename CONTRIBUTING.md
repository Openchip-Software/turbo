# Contributing

Thanks for your interest in contributing to Openchip TURBO! We welcome bug reports, feature suggestions, documentation improvements, and code contributions from the community.

## Getting Started

- Consider emailing the TURBO authors to discuss the improvement.
- Open an issue to report a bug or suggest an enhancement.
- Submit a pull request with a clear description of your changes.
- Keep contributions focused, tested, and easy to review.
- Be respectful and constructive when collaborating with others.

## Acknowledging Sources

If your contribution is based on external resources, articles, code samples, or other references, please include a note acknowledging those sources where appropriate.
