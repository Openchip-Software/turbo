# Security Policy

## Reporting a Vulnerability

We encourage responsible disclosure of security vulnerabilities. If you believe you have identified a security issue in Openchip TURBO, please contact us at **psirt@openchip.com** so that we can investigate and address the issue appropriately.

### How to Report

Please send vulnerability reports to:

**psirt@openchip.com** 

Please do not report security vulnerabilities through public GitHub issues.

To help us investigate, please include where possible:

- A description of the vulnerability
- Steps to reproduce the issue
- Impact assessment
- Affected version(s)
- Any supporting logs, screenshots, or proof-of-concept code

## What to Expect

After receiving a report, we will:

1. Acknowledge receipt of the report.
2. Assess the severity and impact.
3. Investigate and, if appropriate, develop a fix.
4. Coordinate disclosure as appropriate.
5. Communicate remediation guidance when available and appropriate.

## Scope

This policy covers:

- TURBO CLI
- TURBO-tracer
- TURBO-tracer-shared
- Official release packages

Third-party dependencies are subject to their own security policies and maintenance processes.

## Responsible Disclosure

We ask security researchers to:

- Make a good-faith effort to avoid privacy violations, data loss, or disruption.
- Provide sufficient information to help reproduce and investigate the issue.
- Allow reasonable time for the issue to be investigated and addressed before public disclosure.

We appreciate the efforts of security researchers and users who help improve the security of the project.
